# PartyBox 派对盒子（演示版）

派对游戏 / 充气城堡出租的移动端 App 演示：React + Vite 写界面，Capacitor 打包成安卓 APK。
参考对象是一家做充气城堡、水上游戏、派对套餐出租的网店，只参考了业务形态，界面、文案和图标都是重新做的。

## 功能
- 首页：搜索、5 个分类入口、热门推荐、派对攻略
- 分类页：按分类筛选商品
- 商品详情：尺寸、适合年龄、是否含工作人员；选租用日期、天数、数量后加入购物车或直接预订
- 购物车：小计 + 运送安装费 = 合计
- 下单：填写联系人、手机号、城市、地址、备注，生成订单号
- 我的：订单记录、中英文切换、关于我们、联系电话

## 制作思路
1. **先定形态：要在安卓手机上用。** 没有选纯原生安卓（Kotlin），而是用网页技术写界面，再用 Capacitor 套一层安卓壳。
   好处是一套代码既能在浏览器里看，也能打成 APK，以后要出 iOS 版也能复用；演示阶段改起来最快。
2. **按租赁业务拆页面。** 出租和普通网购不一样，关键是“哪天用、用几天”，所以商品详情里放了租用日期和天数，
   价格按“单价 × 天数 × 数量”算，结算时再加运送安装费。
3. **按手机习惯做布局。** 底部 4 个标签栏（首页 / 分类 / 购物车 / 我的），详情页和购物车底部固定操作栏，
   单列 + 两列卡片，适配刘海屏的安全区域；用 HashRouter，保证打包进 App 后页面跳转不出错。
4. **演示阶段不做后台。** 商品数据写在 `src/data.js`，购物车和订单存在手机本地（localStorage），
   老板看效果不需要服务器；确认方向后再接后台，页面基本不用改，只需把数据来源换成接口。
5. **中英文切换。** 界面文字集中在 `src/i18n.jsx`，商品数据每条都带 `zh` / `en` 两份，加新语言只需加一组字段。
6. **商品图暂用 Emoji + 渐变色块。** 避免使用别人的图片，等有真实照片再替换 `Thumb` 组件即可。

## 目录结构
```
src/
  data.js        演示数据：分类、商品、套餐、攻略文章
  i18n.jsx       中英文文案与语言切换
  store.jsx      购物车与订单（存本地）
  components.jsx 公共组件：顶部栏、商品卡片、价格、缩略图
  App.jsx        路由与底部标签栏
  pages/         各页面：首页、分类、详情、购物车、结算、我的、文章
android/         Capacitor 生成的安卓工程
```

## 本地运行
需要先装 [Node.js](https://nodejs.org)（LTS 版本）。
```
npm install
npm run dev          # 浏览器打开 http://localhost:5173
```
手机和电脑连同一个 Wi-Fi 时，可以用手机打开终端里显示的 `Network:` 地址。

## 打包安卓 APK
需要 JDK 17+ 和 Android SDK（装 Android Studio 最省事），并设置 `ANDROID_HOME`。
```
npm run android:apk
```
产物：`android/app/build/outputs/apk/debug/app-debug.apk`
